\# Smart Coil Base EV Charging Station with IoT integration



\## Project Overview

This project is an IoT-based EV charging station using ESP32 and Razorpay payment integration.



\## Components Used

\- ESP32

\- Using MQQT protocol for payments

\- IR Sensor

\- Servo Motor

\- Battery

\- Voltage Divider

\- Razorpay



\## Features

\- Vehicle detection

\- Automatic timer start

\- Charging cost calculation

\- QR code payment

\- Battery monitoring
